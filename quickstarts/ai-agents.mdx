Connect your agent to the hosted Molpha MCP server, look around without a wallet, then run a paid round signed by your own wallet. It takes about five minutes.

<Info>
Prefer a server that holds its own signer and runs unattended? Use the [local stdio server](/mcp/local) instead. [MCP overview](/mcp/overview) compares the two.
</Info>

<Steps>
  <Step title="Add the server">
    The hosted server needs no install and no keys.

    <CodeGroup>
    ```sh Claude Code
    claude mcp add --transport http molpha https://mcp.molpha.io/mcp
    ```

    ```json Cursor (.cursor/mcp.json)
    { "mcpServers": { "molpha": { "url": "https://mcp.molpha.io/mcp" } } }
    ```

    ```json VS Code (.vscode/mcp.json)
    { "servers": { "molpha": { "type": "http", "url": "https://mcp.molpha.io/mcp" } } }
    ```
    </CodeGroup>
  </Step>

  <Step title="Explore without a wallet">
    Read tools work straight away. Try:

    > Use Molpha to show the current capabilities: registry version, node count, chains and verifier addresses. Then derive the sourceId for `https://api.example.com/v1/finalized/price` at `$.price`. Make no writes.
  </Step>

  <Step title="Fund a testnet wallet">
    Paid rounds are signed by **your** wallet, never by the server. Use a dedicated devnet wallet with a little Devnet USDC from [Circle's faucet](https://faucet.circle.com/) (choose **USDC** on **Solana Devnet**).
  </Step>

  <Step title="Run a pay-per-request round">
    Ask for a quote first, then the round:

    > Call `get_x402_status` for 3 signatures with payer `<your wallet address>` and tell me the price. Then run `prepare_x402_round` for the same source with 3 signatures for the EVM chain and give me the transaction to sign.

    Sign the returned USDC transfer with your wallet and **do not broadcast it**. Pass it to `execute_x402_round`: the gateway settles the payment and returns the signed attestation, verifier arguments and a payment receipt.
  </Step>

  <Step title="Use the attestation, not the summary">
    The trust anchor is the signed attestation the tool returns, not the agent's prose. Verify it in your contract or service before acting on the value. See [Verify on EVM](/verifiers/evm).
  </Step>
</Steps>

## Already have a subscription?

Sign in with your wallet instead of paying per round: `begin_session` returns a text message, your wallet signs it, `complete_session` returns a session token, and `execute_subscription_round` runs rounds against your plan. The wallet must be the subscription owner or one of its [delegates](/access-models/delegates). See [Sign in with your wallet](/mcp/hosted#sign-in-with-your-wallet-siwx).

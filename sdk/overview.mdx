[`@molpha/sdk`](https://www.npmjs.com/package/@molpha/sdk) is the TypeScript client for Molpha. This page covers installation, initialization and the main methods; for an end-to-end walkthrough, start with the [backend quickstart](/quickstarts/backend).

The SDK has three parts:

- **`sdk.gateway`** ([`MolphaGateway`](/sdk/gateway-api)) runs signing rounds and returns an [`Attestation`](/sdk/reference#attestation).
- **`sdk.solana`** ([`MolphaSolanaClient`](/sdk/reference#molphasolanaclient)) manages subscriptions, submits attestations to Solana `Feed` accounts and reads them.
- **Verifier argument builders** ([`buildEvmVerifierArgs`](/sdk/reference#buildevmverifierargs), [`buildStarknetVerifierArgs`](/sdk/reference#buildstarknetverifierargs)) map an `Attestation` onto the EVM and Starknet `verify` calls, with no ethers, viem or starknet.js dependency.

## Installation

```bash
npm install @molpha/sdk @anchor-lang/core bn.js
```

- Requires Node.js `>=20.19.0`. The package is ESM-only and marked `"sideEffects": false`.
- `@anchor-lang/core` and `bn.js` are peer dependencies used by the Solana client. You do not need `@solana/web3.js`, `@coral-xyz/anchor` or `@solana/spl-token`.
- Node-only helpers (`walletFromKeypairFile`, `loadKeypair`) live in the `@molpha/sdk/utils` subpath so they stay out of browser bundles.

## Initialize

```ts
import { homedir } from "node:os";
import { join } from "node:path";
import { web3 } from "@anchor-lang/core";
import { MolphaSDK } from "@molpha/sdk";
import { walletFromKeypairFile } from "@molpha/sdk/utils";

const sdk = new MolphaSDK({
  connection: new web3.Connection("https://api.devnet.solana.com", "confirmed"),
  wallet: walletFromKeypairFile(join(homedir(), ".config/solana/id.json")),
});
```

`walletFromKeypairFile` reads the path as given and does not expand `~`.

| Option | Default | Meaning |
|---|---|---|
| `connection` | required | Solana `web3.Connection`. |
| `wallet` | required | A [`MolphaWallet`](/sdk/overview#wallet). Signs Solana transactions and gateway requests; its public key is the default subscription owner. |
| `endpoints` | `DEFAULT_GATEWAY_ENDPOINT` (`https://gateway.molpha.io/`) | A gateway URL, a `{ url, gatewayAuthority }` object, or an array of them for failover. See [endpoints](/sdk/gateway-api#endpoints). |
| `programId` | `MOLPHA_PROGRAM_ID` | Molpha program. Also bound into gateway request auth. |
| `idl` | `MOLPHA_IDL` | Anchor IDL. Override only when pinning a different deployment. |
| `commitment` | Anchor default | Commitment for Solana reads and transactions. |

## Main methods

| Method | What it does |
|---|---|
| [`sdk.gateway.requestSignedData(opts)`](/sdk/gateway-api#requestsigneddata) | Run one gateway round and return an `Attestation`. |
| [`sdk.gateway.prepareContext()`](/sdk/gateway-api#preparecontext) | Fetch registry inputs and nodes once, to reuse across rounds. |
| [`sdk.requestAndSubmit(opts)`](/sdk/gateway-api#requestandsubmit) | Run a round and submit it to Solana. Returns `{ result, signature, feed }`. |
| [`requestMany(sdk, feeds, opts?)`](/sdk/reference#requestmany) | Update many feeds with bounded, adaptive concurrency. |
| [`sdk.solana.getPlan(plan)`](/sdk/reference#molphasolanaclient) | Read a plan's on-chain price and limits. |
| [`sdk.solana.subscribe(plan, { maxPriceUsdc })`](/sdk/reference#molphasolanaclient) | Buy a subscription in USDC, with a price ceiling. |
| [`sdk.solana.submitAttestation(attestation, opts?)`](/sdk/reference#molphasolanaclient) | Verify and write one attestation to the submitter's `Feed` account. |
| [`sdk.solana.submitAttestations(attestations, opts?)`](/sdk/reference#batch-submit) | Submit several attestations of one feed in one transaction. |
| [`sdk.solana.readFeed(sourceId, signaturesRequired, submitter?)`](/sdk/reference#molphasolanaclient) | Read a `Feed` account, or `null` before its first submit. |
| [`deriveSourceIdString(apiConfig)`](/sdk/reference#derivation-helpers) | Compute the `sourceId` of an API config. |
| [`buildEvmVerifierArgs(result, { maxAge })`](/sdk/reference#buildevmverifierargs) | Arguments for the EVM verifier's `verify`. |
| [`buildStarknetVerifierArgs(result, { maxAge })`](/sdk/reference#buildstarknetverifierargs) | Arguments for the Starknet verifier's `verify`. |

You can also construct `MolphaGateway` or `MolphaSolanaClient` on their own; see [clients](/sdk/reference#clients).

## Wallet

`MolphaWallet` is an Anchor `Wallet` with an optional `signAuthMessage`. Every gateway request carries a signature over a `RequestAuth` digest (see [gateways](/gateways/overview)). A keypair wallet from `walletFromKeypairFile` signs it with its `payer` key automatically. A browser wallet adapter has no `payer`, so supply `signAuthMessage`:

```ts
import type { MolphaWallet } from "@molpha/sdk";

const wallet = {
  publicKey: adapter.publicKey,
  signTransaction: (tx) => adapter.signTransaction(tx),
  signAllTransactions: (txs) => adapter.signAllTransactions(txs),
  signAuthMessage: async (msg) => new Uint8Array(await adapter.signMessage(msg)),
} as MolphaWallet;
```

The `as MolphaWallet` assertion is needed because the Anchor `Wallet` type declares `payer`. A wallet with neither `payer` nor `signAuthMessage` sends an all-zero auth signature, which the gateway rejects with HTTP 401.

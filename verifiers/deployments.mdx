## Network status

- **Node set.** Nodes are run by independent operators admitted by the protocol authority. Each posts a USDC deposit and can be slashed with on-chain evidence.
- **Audit.** No external audit has been completed. Mainnet follows the audit.
- **Service level.** Devnet has no uptime guarantee, and addresses can change between releases.

The full trust model is in [Security model](/protocol/security-model).

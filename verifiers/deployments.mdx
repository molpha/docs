## Live today

- **Solana program on Devnet** (program ID above): node registry, USDC subscriptions and plans, job + feed creation, permissionless `submit_data_update`, stateless `verify_data_update`.
- **SDK** — [`@molpha-oracle/sdk`](https://www.npmjs.com/package/@molpha-oracle/sdk) v0.4.0: the full consumer flow (subscribe → create job → execute round → submit/verify → read feed) plus framework-agnostic EVM and Starknet verifier argument builders.
- **EVM verifiers** — deployed on Ethereum Sepolia, Arbitrum Sepolia, Avalanche Fuji, and BSC testnet.
- **Starknet verifier** — deployed on Starknet Sepolia, with cross-chain parity tests proving that unmodified EVM-produced signatures verify on Cairo.

## Not yet implemented

- **Node rewards and settlement accounting** — round receipts and reward crediting ship in the next milestone (Brebeneskul).
- **Slashing and dispute resolution** — proof-based slashing is a later milestone; the testnet node set is permissioned.
- **Mainnet** — gated on a full protocol audit.

<Warning>
All deployments are **pre-audit testnet** contracts with a permissioned node set. There is no uptime SLA and no economic security (staking/slashing) backing testnet data. Do not rely on them for value. See the [Security Model](/protocol/security-model) for the full trust assumptions.
</Warning>

---
title: "Molpha Oracle Protocol"
description: "Turning any API into verifiable on-chain data"
---

Molpha is a pull-native oracle protocol. Independent nodes fetch data from any HTTP API, converge on a canonical value, and sign it once with a threshold aggregate signature — verifiable on Solana, EVM, and Starknet without per-chain feeds or bridges.
